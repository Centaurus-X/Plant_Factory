# Support

Use GitHub Discussions for architecture, integrations, deployment planning and
ideas. Use issues for reproducible defects with sanitized fixtures. Do not post
credentials, proprietary drawings, plant topology or vulnerability details.

Security reports belong in GitHub private vulnerability reporting as described
in `SECURITY.md`.

Architecture review, custom engineering, symbol/adapter development,
deployment and validation may be available separately; see
`COMMERCIAL_LICENSE.md`. Community support is best effort and has no SLA.
