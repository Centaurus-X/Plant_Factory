# Code of conduct

This project values technically rigorous, respectful collaboration. Discuss
evidence, behavior and trade-offs; protect confidential plant information;
disclose uncertainty; and keep reviews focused on the work.

Harassment, discrimination, threats, doxxing, deliberate disruption,
sexualized conduct and publication of private information are not acceptable.
Maintainers may remove content or restrict participation when necessary.

Report conduct concerns through a private channel to the repository maintainer.
Do not use a public issue when a report contains identifying information.
